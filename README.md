# Система учёта прививок животных

## Назначение
Приложение предназначено для ведения и упрощения учета вакцинаций домашних и сельскохозяйственных животных. Оно решает задачу хранения информации о прививках в одном месте, позволяет отслеживать сроки ревакцинации и своевременно напоминать владельцам и ветеринарным специалистам о необходимости очередной вакцинации.

## Целевая аудитория
Основными пользователями могут являться владельцы домашних животных, требующих регулярной вакцинации, ветеринарные клиники, сотрудники приютов и владельцы скотоводческих хозяйств. 

## Предметная область
Предметная область охватывает процессы вакцинации животных: регистрацию животного, назначение и проведение прививки, учет вакцины и дозировки, контроль сроков следующей вакцинации, а также хранение истории прививок. Учет ведется по каждому животному с привязкой к владельцу и ветеринарному специалисту.

## Основные сущности
- Животное
- Вакцинация
- Препарат
- Дата
  
## Основные функции
- Добавление информации о животном
- Фиксация проведённой вакцинации
- Поиск информации о животном
